# Review reasoning for a learning requirement

Tracked by [JERRY-88](https://linear.app/jerryjin/issue/JERRY-88). **Review my work** appears beside a requirement's status inside its existing topic details. It brings together the learner's saved reasoning for that exact unit, target and concept/proof/application kind. Ordinary lessons and delayed checks retain their identities; chapter challenges remain separate. This is an on-demand inspection tool, not a dashboard or a new source of learning credit.

The recent-first list distinguishes submitted diagnostic/practice/exit attempts from a current unsubmitted answer or lesson in progress. Selecting a record shows its full original question, answer, feedback, next step, help status and criterion assessments. Assessment details retain the original tutor/model and timing. Original requirement wording remains available when the current objective changed. Obsolete source, missing/mismatched recorded question kinds and incomplete proof assessments remain qualified; an incomplete proof retains its original tutor grade separately from its missing criteria. No grade is rewritten or promoted to a mastery claim.

The projection contains no answer keys, hints or future questions. Reading or cancelling never edits a session or records new help. **Open saved lesson** explicitly navigates to the selected record's parent lesson; it does not change its phase or replay a historical assessment. The current draft stays with its own lesson. No persistence schema or provider/reader behavior changed.

The native sheet uses succinct [list rows with full details](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables) and a scoped task with an explicit [Close action](https://developer.apple.com/design/human-interface-guidelines/sheets). The existing glass primary control is retained. Up/Down selects records; **Read selected work** / **Choose another record** and ⌘R switch keyboard focus between the list and the scrollable content. Space pages through the selected reasoning; Return opens its lesson and Escape closes the history.
