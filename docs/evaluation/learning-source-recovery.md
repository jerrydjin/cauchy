# Recover saved work after a source change

Tracked by [JERRY-85](https://linear.app/jerryjin/issue/JERRY-85). A saved lesson whose PDF or verified transcription changed now explains the problem where the learner left their work. **Review current source** opens the first affected PDF page, including with ⌘Return; **Back to learning path** provides the next route. The page comes from actual saved passage provenance, without parsing an error message. Removed or invalid page references fall back to the nearest available page; an empty legacy source uses a bounded current source page.

Saved questions, answers, teaching and explanations remain inspectable. Answer and clarification drafts use selectable read-only content while their source is obsolete. Grading, new tutor requests, hints, solution reveal and prerequisite generation are unavailable against that old source. A saved clarification draft remains accessible even if no tutor reply exists. Saved delayed checks and chapter arguments also show source recovery on the learning path rather than a stale Continue action.

Reviewing current notes or saved help does not rewrite the old session's assistance flags, attempts, source, schedule or drafts. Current-source access retains its existing assistance policy. Recovery does not clear source obligations, replace the lesson, earn progress or certify revised teaching. A new lesson still requires the learning path's existing source checks. No persistence schema or reader behavior changed.
