# Tutor attribution for fresh questions — 23 October 2026

[JERRY-116](https://linear.app/jerryjin/issue/JERRY-116) corrects an offline-reproduced attribution error. After successful practice, a replacement ordinary exit question can be generated by a different provider/model from the original lesson. Previously the unsubmitted requirement-history record and its Markdown export still named the original lesson creator. The accepted question and draft were correct; their attribution was wrong.

The regression fails on `e1baa31` in `/tmp/cauchy-attribution116-red.xcresult`, with log and summary alongside it: actual provider, model and selected-export assertions fail. This uses a local authored tutor, not a live model request.

## Resulting behavior

Optional `LearningSession.exitQuestionAttribution` records the actual tutor only when a validated replacement question is accepted. The original session's immutable provider/model stays intact. Requirement-history drafts resolve their current content through this saved attribution; the existing export uses that same read-only projection. A missing question model remains missing, including when the original lesson has a model name. Returning to diagnostic, teaching or practice uses the lesson's recorded creator rather than a later exit-question tutor.

Delayed checks generate a new question but reuse earlier teaching. Optional `lessonAttribution` keeps the inherited teaching's recorded creator, while the new review retains its own session/question attribution. Returning to teaching within that review therefore identifies the earlier lesson correctly. Existing assessed attempts continue to identify the tutor that graded them, including a third provider/model chosen after question generation. No old grade, answer, question, source or target is rewritten.

Older records decode without either optional field and retain their existing recorded fallback. The implementation does not reconstruct missing historical authorship from later preferences. These fields describe the current question and inherited lesson; they do not add retrospective question-author records to every earlier graded attempt. Historical assessment attribution remains the grader's identity.
